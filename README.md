# Float damage text
This mod is primarily focused on displaying numerical damage values and status effect text, along with icons representing the corresponding damage types.

I'm a Spanish-speaking developer, so please excuse the fact that the source code is in Spanish. I'll work on translating the source code into English later.

If you have any questions, suggestions, or have found a bug, you can visit my mod forum section on the official Mindustry server and ping me using my username, **rain_dilue**.

If you request it, I can make a guide on how to modify my mod to implement your unique damage types from your mods, and you can also send me a message.

# Features

## ![Icon](assets/sprites/icon-kinetic.png) Damage calculation
This mod has three types of damage calculation, **raw**, **true** and **both**.

## ![Icon](assets/sprites/burning-icon.png) Damage icon
Each type of damage has its own custom icon that represents its "element" based on the altered state it produces. ![Icon](assets/sprites/wet-icon.png)

## ![Icon](assets/sprites/damage-render-icon.png) Animation and rendering
If you activate **enriched effects**, the texts will have very beautiful special effects.

# Installation
 1. Download the latest release.
 2. Import the mod from **Mindustry**.
 3. Configure the mod from the options section in the game.
 4. Enjoy!
